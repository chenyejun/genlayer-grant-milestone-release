# Documentation Project Guide

This guide is public and is the evidence for milestone 1 ("Full guide"). It covers how to install the project and how to use it.

## Install

1. Clone this repository: `git clone https://github.com/chenyejun/genlayer-grant-milestone-release.git`
2. Change into the repository directory: `cd genlayer-grant-milestone-release`
3. Read the `README.md` file in the repository root for the project overview.
4. No extra dependencies are required to read this documentation: any Markdown reader or a web browser is enough.

## Usage

1. Open this guide (`evidence/guide.md`) in a Markdown reader or on GitHub.
2. Follow the install steps above to get the repository locally.
3. Use the outline in `evidence/outline.md` to navigate the documentation sections: overview, milestones, install, and usage.
4. The guide covers install and usage, and it is public.
